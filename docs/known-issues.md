# 已知问题与兼容边界

此页描述 0.2.0 开发和验收中的真实边界。主要高级效果、独立音轨和实时预览已经实现，不再沿用 0.1.0 的未实现列表。

## 采集验收

- 显示器/区域已使用 FFmpeg Desktop Duplication。完整4K桌面缩为1080p的30分钟活动负载测试得到1800秒、108000帧、60/1，编码进程private约975MiB稳定；FFmpeg报告2419个重复帧、41个丢弃帧。该负载是真实桌面活动，未宣称每帧均为新的运动图案。旧ScreenRecorderLib桌面后端约44.15fps的样本仅保留为历史调查。应用取消60秒上限，保留内存与磁盘保护。
- 独立 WASAPI WAV 已通过30分钟静音填充与脉冲验收：1800.037188s，221/221脉冲检出，音频相对触发中位1.979ms、绝对P95 7.671ms、线性漂移0.0944ms/min。它验证此端点的声音轨时钟，不代替视频与音频的端到端同步验证。
- 同时区域视听采集30分钟：1072组检出事件全部配对，绝对P95 70.790ms、最大94.123ms，达到长片100ms建议目标。名义1080组中8组未检出，原因未分类；系统回环可能混入其他桌面声源。首20秒P95为65.623ms，短片50ms目标未稳定通过。项目以单调时钟及暂停区间对齐，仍提供手动偏移校准。
- 窗口录制当前跟踪窗口的**可见桌面矩形**。遮挡层会进入视频；最小化、关闭、跨显示器及超出单显示器边界会触发说明与收尾。它不提供后台窗口独立捕获。
- 本机没有物理摄像头/麦克风完整验收条件；设备枚举、独立采集接口、摄像头导入/布局/声音和运动渲染已实现。热插拔、权限撤销、多显示器混合DPI及负坐标还需对应设备矩阵。

## 编辑与工程

- DogSC导入器只读处理schema 23–27并复制资源，原工程不覆盖。已验证构造的schema fixture、路径安全与主要高级字段；没有原Mac真实工程时，不承诺全部字段保真或往返兼容。近似曲线、平台壁纸和不支持资源列在 `dogsc-import-report.json`。
- 首次有声播放先生成混音M4A缓存，视频使用持久解码器实时合成。长音轨首次准备可能等待；高分辨率复杂效果的实际预览速度取决于硬件。默认1440宽/30fps，可在设置切换960/1440/1920宽与30/60fps。
- 摄像头暂停后的独立同步区间已用于预览、声音与导出；时间线仍将相机绘成整体包络，检查器提示内部间隙没有相机画面。
- 当前GPU每帧最多4个区域柔化、8个前景图层和1个背景；超限明确报错。多贴图、样机文字和摄像头共享前景容量。
- 光标提供箭头、圆点、圆环、三档移动平滑及点击反馈/静止隐藏，未搬运原版全部平台光标素材。Smooth 轨道最多缓存 200 万个活动采样，达到上限时给出错误；长静默区间会跳过稳定采样。自定壁纸与循环视频可导入，Apple系统壁纸不会随包分发。
- 画布拖动在松开时提交历史；部分快捷键与窗口控件遵循Windows行为。Windows窗口标题按钮与macOS原生窗口控制存在平台差异。
- 中断恢复尽量读取已封装视频、独立音轨、标记和指针；没有有效时间锚点的素材会给出校准说明。没有可解码帧的损坏MP4不能保证修复，原始素材与诊断日志保留。

## 安装与发行

已验证平台是本机 Windows 11 x64。Windows 10、ARM64、Windows N、不同显卡驱动和干净虚拟机尚不计通过。安装包未使用商业代码签名证书，Windows可能显示未知发布者。

当前为本地交付；自动签名更新服务和公开反馈后台尚未建立，应用提供版本、手动更新说明、本地源码/许可与诊断位置。公开分发包含GPL组件的FFmpeg包前，仍需完成该实际构建全部对应源码及许可材料。不会复用上游捐赠账号或收款码。
