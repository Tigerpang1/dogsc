# 已知问题与后续工作

当前状态：阶段 1 技术验证与阶段 2 基础闭环。完整功能迁移未完成。

## 必须优先解决

1. 采集首帧 PTS 与 Stopwatch 的精确对应关系未得到原生库公开支持。实际状态通知延迟约数百毫秒，不能直接作为音画或鼠标同步误差。需要带闪屏/音频脉冲与鼠标事件的真实采集测量及时间锚点。
2. 长录制压力测试曾出现 Private Bytes 持续增长。实时录制关闭 faststart 后视频可以持续写入，但仍需完成内存归因与 30 分钟稳定性验证。测试会以资源上限保护本机，不能把短测试结果外推为长录制通过。
3. 录制目前将系统声音与麦克风交给原生库混合进主视频，不提供独立素材轨或独立混音。
4. 首次有声预览需要生成代理视频，长素材即时播放与连续拖动性能还需优化；导出存在 CPU 解码、GPU 上传、staging 回读和编码上传，尚未实现完整零复制链路。
5. 本机运行通过不等于干净 Windows 环境通过。需要干净 VM/实体机安装、启动、录制、导出和卸载验证，尤其 VC++ Runtime、Media Foundation 和显卡驱动。

## 尚未完成的功能

摄像头录制与布局；独立麦克风/系统音轨；录制暂停与无缝恢复；完整多效果轨道、效果移动/裁剪和复制粘贴；时间线缩放；多种光标皮肤和静止隐藏；画布预设、裁切编辑；开场动画、屏幕倾斜/透视/3D、聚焦虚化、贴图、样机外框、场景预设；完整可访问性和本地化；自动更新；原项目版本导入与真实 macOS 项目对照。

## 尚未验证的场景

不同 GPU/驱动、Windows N、无开发环境机器、真实麦克风声学输入、摄像头、多显示器跨屏及混合 DPI、负坐标、窗口移动/尺寸变化后的内容坐标、设备拔出、权限拒绝、磁盘耗尽、睡眠恢复、目标窗口关闭，以及另一个录屏工具对辅助窗口排除标志的行为。

1080p60 的编码与合成已获得本机实验数据，但不声明所有硬件都能达到实时性能。4K60、长片同步 ≤100ms 仍需单独测量。
