# 历史兼容调查（0.2.3）

当前 Windows Beta 的已知限制、下载和媒体分发材料见 [0.2.17 版本说明](release-0.2.17.md)，逐项状态见 [验收台账](acceptance-ledger.md)。

以下保留 0.2.3 开发候选的历史调查，不能直接作为当前待办或发布状态：其中长录同步、窗口遮挡捕获、麦克风采集、预览与安装流程后来已有修改和实测。0.2.5 证据见 [迁移差距登记](migration-gap-register.md)，0.2.6 界面增量见 [UI 验收记录](ui-craft-validation.md)。Windows 分支吸收结果见 `windows-port-integration.md`。

## 采集验收

- 显示器/区域已使用 FFmpeg Desktop Duplication。完整4K桌面缩为1080p的30分钟活动负载测试得到1800秒、108000帧、60/1，编码进程private约975MiB稳定；FFmpeg报告2419个重复帧、41个丢弃帧。该负载是真实桌面活动，未宣称每帧均为新的运动图案。旧ScreenRecorderLib桌面后端约44.15fps的样本仅保留为历史调查。应用取消60秒上限，保留内存与磁盘保护。
- 当前音频实现用连续设备位置拼接包，只在锚定、设备位置倒退或明确不连续时重新对齐；QPC用于时钟锚点、漂移与残差诊断。30秒真实系统回环试验得到18/18个视听cue，原始A−V绝对P95为54.736ms；扣除同分析器fixture中位偏差后的估计为21.885ms，此估计不是物理时钟校准，不能替代原始偏差。当前实现的30分钟长测仍待完成。
- 旧到达时刻实现的独立WASAPI长测（221/221脉冲、P95 7.671ms）与区域视听长测（1072组、P95 70.790ms）是历史证据；较早QPC候选v8只匹配485/1080个名义cue、后段WAV全零，不能计为同步通过。新短测记录并临时恢复自有ffplay进程会话的音量与静音状态，结束后读回确认恢复；旧v8未记录会话状态，无法追溯认定其失败原因。
- .NET 10候选 `surfaces-net10-v5` 完整UIA为43/43、浮层19/19、导出面板15/15。后续v6修正主窗口主题继承，浮层19/19通过并重新查看深色截图；时间线浅色效果片段已改为深色字，浅深主题的15项离屏布局、文字与实际像素检查通过。新时间线仍待实机截图，高对比模式仍待真实系统验证。上述结果不自动继承到0.2.3发行包，最终同包播放、录制、导出及安装卸载仍需完成。
- 窗口录制已使用Windows Graphics Capture独立窗口源。固定产品服务捕获同进程动态自绘窗口得到正常可解码画面；独立进程的静态目标即使实际可见且桌面像素正确仍得到黑帧。两轮的动态/静态内容不同，尚不能归因于进程边界；同一目标的Raw WGC与ScreenRecorderLib、静态与动态矩阵已准备，待实机运行。遮挡、移动、缩放、最小化和关闭的整套验收尚未完成。
- 本机能枚举HECATE麦克风，但尚未完成实际输入采集；摄像头枚举为空，只有一台150%缩放显示器。独立采集接口、摄像头导入/布局/声音和运动渲染已实现。热插拔、权限撤销、多显示器混合DPI及负坐标还需对应设备矩阵。

## 编辑与工程

- DogSC导入器只读处理schema 23–27并复制资源，原工程不覆盖。已验证构造的schema fixture、路径安全与主要高级字段；没有原Mac真实工程时，不承诺全部字段保真或往返兼容。近似曲线、平台壁纸和不支持资源列在 `dogsc-import-report.json`。
- 首次有声播放先生成混音M4A缓存，视频使用持久解码器实时合成。长音轨首次准备可能等待；高分辨率复杂效果的实际预览速度取决于硬件。默认1440宽/30fps，可在设置切换960/1440/1920宽与30/60fps。
- 解码图片与样机标题文字共用每个 `SceneAssetLoader` 256MiB缓存预算，超预算按最近使用顺序驱逐，单项超预算只供当前帧使用。该数值是素材缓存预算，不是整个应用的内存上限；GPU纹理、当前帧、解码器和并行导出仍另占内存。
- 摄像头暂停后的独立同步区间已用于预览、声音与导出；时间线仍将相机绘成整体包络，检查器提示内部间隙没有相机画面。
- 当前GPU每帧最多4个区域柔化、8个前景图层和1个背景；超限明确报错。多贴图、样机文字和摄像头共享前景容量。
- 相邻/重叠贴图的背景处理会预计算交接关系，最多允许65536个重叠交接；超限明确提示。贴图高斯柔化与macOS Core Image近似实现不同，预览和导出共享同一Windows渲染路径，尚未做跨平台逐像素认证。
- 光标提供录制形态跟随、固定箭头/手型/文本、圆点和圆环，未搬运原版全部平台光标素材。Smooth 指针轨道最多缓存 200 万个活动采样；自动镜头轨道全项目最多 100 万个 120 Hz 活动采样，达到上限时明确报错。长静默区间会跳过稳定采样。自定壁纸与循环视频可导入，Apple系统壁纸不会随包分发。
- SDR 导出使用 BT.709 YUV 矩阵、sRGB 传递曲线和 limited 范围；七色色卡通过预览/软硬编码往返测量。HDR、广色域及不同传递曲线素材混合的完整色彩管理尚未实现。
- 画布拖动在松开时提交历史；部分快捷键与窗口控件遵循Windows行为。Windows窗口标题按钮与macOS原生窗口控制存在平台差异。
- 中断恢复尽量读取已封装视频、独立音轨、标记和指针；没有有效时间锚点的素材会给出校准说明。没有可解码帧的损坏MP4不能保证修复，原始素材与诊断日志保留。

## 安装与发行

已验证平台是本机 Windows 11 x64。Windows 10、ARM64、Windows N、不同显卡驱动和干净虚拟机尚不计通过。安装包未使用商业代码签名证书，Windows可能显示未知发布者。

当前为本地交付；自动签名更新服务和公开反馈后台尚未建立，应用提供版本、手动更新说明、本地源码/许可与诊断位置。公开分发包含GPL组件的FFmpeg包前，仍需完成该实际构建全部对应源码及许可材料。不会复用上游捐赠账号或收款码。
