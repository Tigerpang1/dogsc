# 95% 收尾计划

更新：2026-10-10。前次已提交源码基线为 `889db72`；本轮新增改动和证据以台账记录为准。应用版本配置为 0.2.7。当前验收分母固定为 33 行，来源及逐行状态见[验收台账](acceptance-ledger.md)。本轮先完成非摄像头功能和交互收尾；摄像头实机条件延期但仍保留在分母中。Mac 工程导入/互通与上游捐赠入口已从本轮范围移除，Windows 功能与交互对照原版的要求保留。

## 当前进度

当前台账有 14 个有限场景证据已销账、16 项待验、3 项延期，没有待修项；这些数字描述证据状态，不代表功能迁移完成率。时间线播放、暂停、左右逐帧、拖动以及中文输入环境下的 `I`/`O` 范围快捷键已有实机证据，FT-12 据此通过。MP4、M4A、导出取消清理及进度证据覆盖FT-29至FT-31。设置页错误提示、修正、保存和重启持久化已实机通过；FT-32要求的外观选项不改变导出像素仍待验。轨道显隐、吸附和悬浮预览仍待验。Core tests、Integration及离屏保存失败、视觉和文本菜单命令探针通过。目前尚未达到 95% 验收门槛。

整体验收仍要求 33 行中至少 32 行通过。当前先推进可执行的非摄像头收尾，摄像头及在线服务条件延期但仍按台账保留，不改变整体分母或门槛。阶段性收尾不等于达到95%；不得通过删行、拆分复合行或将“待验”记作通过来改变进度。

## 固定执行顺序

| 阶段 | 工作与完成条件 |
|---|---|
| 1. 非摄像头收尾 | 处理待验交互和功能；使用固定复杂工程完成长素材定位、多轨范围导出、裁切与输出尺寸、素材失效恢复、保存失败重试、标记不入画等有限场景。录制或导入→编辑→保存重开→导出闭环通过；缺陷修复后记录复验结果。 |
| 2. 界面验收 | 固定内容工程，检查主窗、检查器、录制条、菜单/下拉、设置、导出界面的浅深色及 100%/150%/200% 显示；模态操作覆盖 Tab/Enter/Esc、取消和返回。验收已有指定场景，不扩成任意设备矩阵。 |
| 3. 交付验收 | 以同一源码提交、便携包和安装器完成有限主流程、安装卸载、源码独立构建及清单核对；按台账逐行更新。只有达到 32/33 且无严重缺陷时，才报告达到 95%。 |

预算按现有差距估算为非摄像头收尾及交付 8–13 小时有效工作时间，不含等待和用户占用主机时间；这是工程估算，不是工期承诺。发现影响架构或固定场景的缺陷时，说明具体影响和修订预算。摄像头实机验收待资源可用后另排，不能用虚拟设备或构造工程替代。Windows 10/ARM64、HDR、公开发行及商业签名不在本轮门槛内。

以 0.2.5 验收提交 `df3ed90` 为旧证据基线，差异核对截至前次已提交源码基线 `889db72`：该区间 Core、Capture、Media 与依赖未变；App 控件主题、时间线控件、菜单、导出窗口有变化，版本配置改为 0.2.7。本轮新增的工程/素材事务、保存失败提示、主素材时长校验和设置交互已有 Core tests、Integration 与离屏探针证据；`desktop-observations.json` 记录时间线操作和范围导出，最新 `integration-final3/result.json` 验证标记帧与基线一致。`main-media-coverage/result.json` 为113项通过的VisualProbe。设置页空值提示、保存与重启持久化已有真实窗口证据；外观选项对导出像素的影响及完整素材重定位用户路径仍待验。旧报告只在实现与配置未变且完整覆盖该行场景时继承，不代表新版本重测。

轻量进度只报已销账场景数、已修复问题、剩余待验/延期项和当前阻碍；不要把证据销账数换算成功能迁移完成率。台账记录证据路径、固定场景和状态；历史报告仅作证据来源，不重复汇总旧版本测试数字。
