# FrameTrail 0.2.2 开发预览

0.2.2继续收敛原版静态细节：检查器标题、选择卡片文字和细边框、位置盘三等分参考线与中心线、导出标题、矢量关闭图标和窗口圆角。修复“仅导出音频”入口仍显示视频模式的问题；导出期间锁定内容类型、文件名及目录，错误或取消后可在同一面板重试。实际M4A、目录失败保护、取消清理及重新导出的12项检查通过。

图片和样机文字缓存现在共享256MiB字节预算，按最近使用顺序驱逐；标题大小写和分隔符不再可能碰撞。新增真实解码和驱逐测试，Core、导入器、GPU/媒体、逐片段音量及两组集成验证通过。App final8构建为0警告、0错误，编辑回归53/53，导出面板真实导出检查12/12；快捷键12/12运行于final7。

时间线补齐按当前选择分割五类效果、Q/W裁切、D删除及Shift+方向键移动五帧。主视频分割按播放头所在片段执行，并正确映射重排和变速；操作可撤销重做。修复中文输入法开启时字母快捷键被吞掉的问题，文本输入框保留输入法行为。屏幕和相机运动裁短后，返回时长限制在剩余片段以内。final8内部编辑回归53/53通过；真实键盘与正常关闭专项12/12使用final7。效果分割沿用原版分段语义，运动进入期或摄像头不同布局之间的分割不承诺任意逐帧无损。

系统声音与麦克风采集改用WASAPI包首帧QPC时间，补齐暂停样本裁切、停止尾包裁切和初始化失败的资源清理。启动与释放串行化，状态和错误通知隔离订阅者异常；主窗口关闭先取消并等待预览，再释放素材与渲染资源。新诊断侧车与4项纯测试通过。20秒交互短测的2020个包、969600帧均为静音；另一项5秒ffplay会话诊断观察到该进程会话静音且音量为0，但旧v8没有会话状态，不能据此解释其30分钟静音段。当前短测与长测仍待复核，详见 `capture-validation.md` 和验证报告。物理摄像头、麦克风、多显示器及原Mac工程仍须对应环境验收。

最新完整UIA在7/32后被前台保护中断，剩余项既不算通过，也未确认是产品失败；较早42/42属于旧候选历史结果。最终全量UIA、发行包真实播放/录制以及安装/卸载仍待可交互验收时段。源码独立重建与候选包内容验证在后台执行，结果由版本候选清单记录。目标“功能迁移95%”和静态外观完全一致尚未达成。

## 0.2.1 历史记录

0.2.1 吸收 `xiaoying8666/dogscwindows` 固定提交的自动镜头跟随、录制光标形态、本机光标资源和色卡验证方法，附带 MIT 来源说明。新增 0.25× 起的慢放、可编辑 Bezier 和弹簧参数、三种原版开场曲线、光标倾斜与四种点击动画；缩放片段也可使用聚焦虚化。真实光标形态采集、带阈值的色彩往返与重排慢放的音调/时长测量见 `windows-port-integration.md`。下面保留 0.2.0 基线的历史验收范围，新增功能的测试结果单独记录。

0.2.1 的 Core、导入器、GPU/媒体探针、逐片段音量、普通集成和1080p60同步检查通过；最终应用的内部编辑回归为39/39。完整桌面 UIA 为41/42，唯一失败来自测试点击恰好落在重排后的剪辑边界；修正选点后，在同一重排布局单独复验贴图完整复制和属性粘贴通过。原失败报告保留，未改写成全量通过。另有高级检查器及聚光/音量两组专项各5/5通过，11页静态截图已更新。详细证据见 `validation-report.md`。

FrameTrail 是面向 Windows 的独立桌面录屏与视频编辑迁移项目，内部代号 FrameTrail。它基于 DogSC `e207d11b111c5e58152238fb64115b2009850547` 的可复用算法与交互目标开发，不是原作者官方版本，也不承诺完全兼容 `.dogscproject`。

0.2.0 已打通本机录制、Windows工程保存、时间线编辑、GPU场景合成、实时预览和MP4/M4A导出。工程包含可恢复备份、相对素材路径、鼠标时钟校准和独立音轨映射；时间线支持分割、裁短、变速、重排、撤销与重做。合成支持自动/手动缩放、屏幕与摄像头运动、开场元素动画、柔化/马赛克、贴图和背景图片/视频等场景效果。实时预览和导出调用共享场景求值与D3D11合成路径。

本机自动验证覆盖GPU与实时预览、项目持久化、时间线编辑、取消清理、范围导出及1440p/4K和30/60fps样片。内部编辑回归28/28、独立桌面UIA回归42/42通过，包含60fps逐帧操作和摄像头同步分段移动、裁切、滑移。真实录制工作流7.9秒输入样片含27个指针事件、2次点击和1个自动缩放片段，编辑为5.925秒后成功导出；70.533秒录制工程编辑为52.9秒后成功导出。便携版隔离 `PATH` 与 `DOTNET_ROOT` 后的播放、暂停恢复和真实录制导出也通过，但仍在开发机上验证。构造DogSC schema fixtures通过，但没有真实Mac项目的完整往返验证；Swift算法对照来自源码分析与数值样本，本机未运行Swift实现。

0.2.0仍是开发预览。新 FFmpeg Desktop Duplication/NVENC 后端已通过本机4K全屏采集缩放为1080p60的30分钟测试（1800秒、108000帧）；独立WASAPI loopback也通过一次30分钟端点测量。正确区域的视听同时30分钟试验已完成，1072组检测cue全部配对，P95绝对偏差70.790ms、最大94.123ms、估算漂移+0.02696ms/min，达到本次长时100ms阈值。名义1080组中8组未检测且未逐项归因；音频使用系统回环，可能混入桌面其他声源。启动前20秒短区间P95为65.623ms，未达到短测50ms阈值。ScreenRecorderLib旧后端的30分钟样片未达到60fps要求。per-user安装版有声播放与卸载检查通过；源码归档有独立解压构建验证脚本。物理摄像头、麦克风、多显示器矩阵和干净虚拟机仍待验收。发行前还需锁定可再分发的FFmpeg构建并备齐对应许可材料。

仓库提供无隐私素材的8秒演示工程及其实际导出，位于 `artifacts/sample/FrameTrail-Demo/`；从源码可用 `scripts/create-sample.ps1` 重建。

已知边界和复现命令见 `known-issues.md` 与 `validation-report.md`；采集测量详见 `capture-validation.md`。当前报告不得解读为迁移阶段完整完成或正式公开发布。

背景、开场、光标、摄像头和声音检查器已按原版源码重新组织为卡片、分组与折叠区，保留实际项目字段与导出行为。时间线图标改为矢量绘制，画面/波形显示有明确启用状态，素材缩放支持原版4倍范围。

- 摄像头效果支持缩放联动与阴影强度；基础摄像头轨可复制并通过完整粘贴替换，替换可撤销，属性粘贴保留目标素材和时间映射。
- 缩放片段保存进入/退出进度锚点，默认值兼容旧工程；时间线裁剪、移动和复制按边界维护锚点。
- 贴图新增背景柔化及是否包含摄像头的选项，并可在显示期间隐藏屏幕或摄像头；预览与 MP4 导出共用处理。
- 区域效果新增 Spotlight、源画面坐标和三种转场，聚光区域保持清晰，区域外按设置压暗。
- 辅助音视频导入保留分段校准和源时钟速率；片段级系统声音、麦克风音量及静音可单独设置，分割和重排保持绑定。
- 修复辅助音频在非零起点、变速和多段混合时提前叠入或延长输出的问题；真实 M4A 的分段频率、音量、静音及首尾空白通过测量。声音检查器修改时间偏移时会一起移动所有同步段，保持源时钟速率，保存重开仍一致。

- 补齐光标 Smooth/Medium/Rapid 三档平滑、点击锚定与二次 Bezier 缓动；鼠标偏移保持独立。
- 样机页改为可操作预览卡片，新增顶栏高度和外圆角；修复内容圆角为零时外框变成方角的问题，预览、导出与鼠标命中共同遵循外框裁切。
- 时间线轨道使用矢量图标，波形使用实际音频峰值绘制连续包络；项目原子保存遇到短暂文件占用时有限重试，持续失败仍保留原工程。

- 修复样机切换沿用上一个样机尺寸、显式零外圆角仍被内容圆角放大的问题；滑杆和开关支持 UI Automation 写入后真实保存。
- 修复屏幕或摄像头异常后未收尾独立轨道的问题，保留可用素材、暂停时钟及恢复记录，并提示恢复位置。
