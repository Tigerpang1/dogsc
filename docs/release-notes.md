# 0.1.0 技术预览发布说明

内部代号 FrameTrail。目标 Windows 11 x64；独立基于 DogSC `e207d11b111c5e58152238fb64115b2009850547` 开发，非原作者官方版本。

本次建立原生录制、项目保存、基础时间线编辑、点击运镜、GPU 共享合成、MP4/M4A 导出和重新打开的闭环。提供自包含便携包、当前用户安装器、源码、测试工具和架构/审计文档。

技术预览对单次录制设置 60 秒上限，并提供内存增长和磁盘空间保护。长录制稳定性尚未完成验收。

已验证真实桌面短录制及媒体导出；已验证合成点击、剪辑、变速、重排、撤销重做、备份恢复、导出取消和重试。1080p60 合成素材可使用 NVENC；合成音画脉冲偏差为 20ms。

长录制稳定性、采集首帧时间、多设备场景、干净机器和高级效果仍在迁移范围内。完整迁移尚未完成。详细未完成项见 `known-issues.md`，实际测量见 `validation-report.md`。
