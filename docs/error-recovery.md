# 备忘录保存与异常提示

备忘录正文仍位于 `%LOCALAPPDATA%\FrameTrail\memo.txt`，外观和位置保存在旁边的 `memo.txt.settings.json`。两类文件分别使用同目录临时文件及原子替换，避免写入失败截断既有内容。

输入后自动保存失败时，备忘录内显示状态，待保存文字继续留在编辑区。再次编辑或关闭窗口会重试。关闭时正文或外观设置未能保存，会取消关闭并显示统一风格的说明；恢复文件访问或磁盘空间后，可以再次关闭。两个文件独立保存：如果正文已成功而设置失败，正文已经更新，窗口仍保留供重试设置。

全局 UI 异常也使用统一的 `SurfaceDialog`。错误提示自身失败或出现嵌套异常时只记录日志，避免递归弹窗。异常日志保存在 `%LOCALAPPDATA%\FrameTrail\logs\errors.log`。

这不保证进程崩溃或强制结束后恢复尚未保存的文字。录屏排除及备忘录真实移动、关闭重开仍按 FT-07 单独验收，离屏失败/恢复检查不替代桌面操作。

源码验证：`artifacts/validation/memo-error-recovery/offscreen-v2/result.json` 的49项检查通过，覆盖两种主题、正文和设置文件被占用、旧文件保留、临时文件清理、关闭取消、解锁重试，以及全局错误重入。状态文字按实际背景检查4.5:1对比度和完整布局；备忘录正文从顶部开始排版。夹具错误写入内存，用户真实备忘录与设置文件哈希未变，见 `user-settings-compare.json`。完整App离屏回归见同目录 `app-regression.log`。
