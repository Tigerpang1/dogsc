# 0.2.10 桌面交互修复候选

0.2.9基本交互验收中，用户报告托盘右键菜单展开后立即消失，无法选择退出。0.2.10将菜单打开排到系统托盘回调结束之后，并使用通知区事件提供的屏幕锚点，减少右键消息和菜单鼠标捕获交错造成的收起风险。实际稳定性仍需复验，不能以构建通过代替。

提词器编辑框使用透明背景，避免默认输入框底色盖住可调透明底层，文字保持不透明。用户随后确认旧0.2.9进程的透明度已恢复，该现象不能归因于尚未部署的本次代码修改。

新增回归覆盖浅深主题、编辑和阅读模式下55%与100%背景的实际像素Alpha，并检查临时隐藏窗口的逐像素透明与合成底色。测试只使用隔离文稿，不显示或激活窗口。正常退出、文稿/外观重启保留，以及录制中关闭编辑器仍须实际验收。

候选代码来自随包 `BUILD-INFO.txt` 标明的源码提交；产物与后台验证以 `artifacts/validation/package-0.2.10/` 的实际报告为准。此文不宣称包已通过或已达到95%。摄像头继续延期，复杂权限场景暂缓。
