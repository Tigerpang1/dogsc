# FrameTrail 技术预览使用说明

本版本面向 Windows 11 x64 的本机技术验证。打开便携目录 `app/FrameTrail.exe`；也可运行安装器按当前用户安装。缺少 Microsoft Visual C++ 运行库时，按安装器提示打开微软官方页面安装 x64 版本。Windows N 版还需要 Media Feature Pack，目前没有实测。

## 录制

技术预览单次录制最多 60 秒。长录制内存行为尚在验证；若本进程 private bytes 较开始增长超过 512MiB，或录制盘剩余空间低于 300MiB，也会主动结束并封装素材。开始录制要求至少 500MiB 可用空间。保护性结束后会显示原因。

1. 左侧选择显示器、指定窗口或区域。区域模式先选择显示器，再点击“框选录制区域”。区域当前须落在同一显示器内。
2. 根据需要启用系统声音和麦克风，选择麦克风和 30/60 FPS。
3. 点击“开始录制”。录制条显示时长，提供标记和结束按钮。`Ctrl+Alt+M` 可添加标记；若快捷键被占用会提示，仍可用按钮。
4. 结束后自动保存项目并进入编辑。项目默认位于当前用户“视频/FrameTrail”目录，每段录制建立独立目录。原始视频放在 `media`，鼠标事件保留为 JSONL。

备忘录自动保存在 `%LOCALAPPDATA%/FrameTrail/memo.txt`。录制条与备忘录使用 Windows 的 `WDA_EXCLUDEFROMCAPTURE` 请求排除；这是系统级行为，并不保证其他录屏工具可以录到这些窗口。失败会记入本机错误日志，跨工具效果仍需验证。

录制时可打开以前的项目继续编辑。不要移动正在录制的素材目录。当前项目的相对路径支持整个目录一起迁移。

## 剪辑与画面

- 选中一个片段，把播放头放在其内部，再分割、裁去左侧或右侧；使用重排按钮改变顺序。“恢复全片”恢复原始素材的完整范围，仍可撤销。
- 速度菜单提供 1、1.5、2、4 倍，音轨会同步调速。当前没有多路音轨独立混音。
- 时间线显示素材缩略图与波形；鼠标拖动播放头时可吸附片段边界。左右箭头逐帧定位，空格播放/暂停，`S` 分割，`Ctrl+S/Z/Y` 保存/撤销/重做。文本框输入时编辑快捷键不触发。
- 右侧可改纯色背景、留白、圆角、阴影及光标显示，然后点击“应用画面设置”。背景格式为 `#RRGGBB`。
- 点击“根据点击生成运镜”建立自动缩放。无点击事件的素材不会自动生成点击运镜。
- 开启“点击手动构图”，点击预览里的目标位置，可在播放头位置添加手动缩放。
- 若独立光标过早或过晚，输入毫秒偏移并应用。正值让光标事件发生得更晚；校准不会改变视频或音轨。

首次播放会先生成带音轨的预览视频。预览与导出使用相同场景计算和 GPU 渲染；修改项目后会重新生成预览。生成时间取决于素材时长和效果，可取消。

## 保存、重新定位与恢复

编辑后自动写入项目，并保留上一次保存的 `.bak`。打开损坏项目时可选择恢复备份，原损坏文件会另存保留。素材丢失时会要求重新选择，并复制到项目内新路径。

“恢复未完成录制”可检查异常中断目录的 `recording-recovery.json`。视频已完成足够封装时可以建立新项目；缺少完整 MP4 索引时会明确报告不能恢复，保留原文件和鼠标日志。该恢复入口目前不能自动重建中断会话的精确鼠标首帧时间。

当前 `.frametrail` 格式与原 `.dogscproject` 不互通。不要重命名原项目尝试导入；可导入其中的视频副本，原效果和轨迹不会随普通视频导入。

## 导出

选择素材分辨率、1080p、1440p 或 4K，选择 30/60 FPS，点击“导出成片”。当前保持项目画布比例。“导出 M4A 音频”要求源素材包含音轨。

硬件编码会先做实际探测，失败后尝试其他编码器并回退软件。进度依据实际处理帧数，剩余时间在有足够样本后估算。取消会终止子进程并清理当前临时输出；已存在的最终文件在成功核验前不会被替换。原始媒体和项目文件受保护。

错误日志：`%LOCALAPPDATA%/FrameTrail/logs/errors.log`。遇到失败请保留项目目录和诊断报告。当前发布包未经过代码签名和全新机器验证，仅作本机技术预览。
