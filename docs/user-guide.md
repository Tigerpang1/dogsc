# FrameTrail 0.2.2 使用说明

FrameTrail 是独立维护的 DogSC Windows 迁移版本，当前产品名为内部代号，支持目标为 Windows 11 x64。便携版解压后运行 `app/FrameTrail.exe`；安装版使用当前用户安装器。首次使用可打开随包 `samples/FrameTrail-Demo/FrameTrail-Demo.frametrail` 查看效果，旁边的 MP4 是实际导出样片。

## 录制

1. 点击主窗口左上角的显示器按钮，打开悬浮录制条。选择显示器、窗口或区域；区域选择限制在一个显示器内。
2. 按需启用系统声音、麦克风和摄像头，选择设备与保存位置。Windows 隐私设置须允许桌面应用访问麦克风/摄像头。设置中的录制帧率为30或60fps，可选最高1080p或原始分辨率。

若出现“无法访问麦克风”，可点击“打开麦克风设置”，检查 Windows“设置 → 隐私和安全性 → 麦克风”中的“麦克风访问”和“允许桌面应用访问麦克风”。调整后返回 FrameTrail，再次开始录制；也可以点“稍后”，关闭麦克风后仅录屏。此提示表示设备访问被 Windows 拒绝，不保证原因一定是隐私开关。
3. 开始后可暂停/恢复、添加标记或停止；`Ctrl+Alt+M` 添加标记。热键被其他应用占用时，状态栏会提示，可使用录制条按钮。
4. 停止后应用保存独立项目目录并进入编辑。主视频、声音、摄像头和鼠标轨迹分别保存，请移动整个目录以保留素材关系。

显示器和区域使用 Desktop Duplication。窗口模式跟踪其可见桌面矩形，遮挡物会录入；最小化、关闭或跨显示器时会结束并提示。录制没有60秒时长上限；磁盘空间和内存达到保护阈值时会停止并保留素材。设备出错时会尽量收尾，无法对齐的独立轨道写入 `recording-warnings.txt`。

录制条和备忘录会请求 Windows 排除自身，设置还可在录制时排除编辑器。本机已验证 FrameTrail 和独立 FFmpeg gdigrab 都遵守该设置；此结果不保证其他捕获工具或系统版本的行为。录制过程中可以打开已有项目继续编辑。

备忘录可保存文本、字号、透明度和窗口位置，下次打开恢复。自动保存失败会在窗口内提示；关闭时保存失败会保留窗口和待保存文字，恢复文件访问或磁盘空间后再次关闭即可重试。详见[保存与异常恢复](error-recovery.md)。结束录制前不要移动项目目录或删除正在写入的文件。

## 编辑

点击时间线定位，拖动片段边缘裁短，拖动主视频片段重排。右键菜单提供变速、左右裁切和导出范围。效果轨道可移动、裁剪；Ctrl或Shift配合点击进行多选，Delete删除，撤销可恢复。

片段右键“速度”可选择 0.25×、0.5×、0.75× 慢放及常用加速倍率。变速会改变成片时长，主音轨和独立音轨共同重排并保持音调；录像本身没有的中间动作帧不会被凭空生成。

画面面板设置比例、裁切、留白、圆角、阴影、样机与背景；背景支持颜色、渐变、网格、动态效果、图片和循环视频。运镜面板编辑自动/手动缩放、屏幕3D和聚焦虚化。光标面板可选择样式、点击反馈、隐藏策略；时间偏移只校准指针，不改变主视频或声音。

摄像头、贴图、柔化和开场效果均按最终时间线参与预览与导出。屏幕暂停后，相机使用独立同步区间；时间线仍显示整体包络，检查器会提示区间间隙没有相机画面。场景预设可保存、改名、覆盖和跨项目应用，相关素材会复制到目标项目。

选中摄像头轨道后，在“摄像头”面板的“形状”卡片中可选圆角方形、圆形、横向、竖向、原始比例或全屏；非圆形卡片可调圆角程度。基础布局作用于全片，“添加摄像头运动”会创建时间线片段，可分别设目标形状、位置、大小、不透明度、进入/回落时长和曲线；几何与透明度在动画期间连续变化。开启“缩放时联动”后，摄像头大小随主画面缩放变化；阴影强度、描边、镜像和蒙版内取景也在该面板调整。复制基础摄像头后，使用“粘贴效果并替换摄像头轨”替换当前唯一摄像头轨道，操作可撤销；属性粘贴保留目标素材和时间映射。场景预设保存场景设置，不保存或替换时间线摄像头轨道。

缩放片段的“聚焦虚化”开关可启用焦点保护效果。可选径向或线性形状，以及“随运镜”“随鼠标”或“固定”目标；焦点位置、范围、虚化、暗化和柔和度可分别调整，线性形状还可设置焦面角度。缩放片段的进入/退出进度锚点由时间线裁剪和移动逻辑维护，默认工程行为不变。屏幕 3D 片段使用同一组聚焦参数。

选中贴图片段后，“边框与阴影”可设描边宽度和颜色、阴影不透明度；阴影开启后可调柔和度及水平/垂直偏移。“动画节奏”支持线性、顺滑、利落和柔和，分别控制贴图入场与出场过渡曲线。贴图还可启用背景柔化，并选择柔化是否包含摄像头；“贴图显示时隐藏屏幕/摄像头”控制贴图时段的对应画面。多个贴图按时间和图层顺序交接，柔化与隐藏状态随片段过渡计算。

| 快捷键 | 操作 |
|---|---|
| Space | 播放/暂停 |
| ← / → | 按源素材帧率移动1帧 |
| Shift + ← / → | 按源素材帧率移动5帧 |
| S | 在播放头分割所选效果；未选效果时分割播放头所在主视频片段 |
| Q / W | 裁去所选效果起点/终点；未选效果时波纹删除主片段的前段/后段 |
| D / Delete | 删除当前所选项 |
| I / O | 设置导出范围起点/终点 |
| Ctrl+C / Ctrl+V | 复制/粘贴所选效果片段 |
| Ctrl+Shift+V | 粘贴同类效果属性，保留目标位置、时长和身份 |
| Ctrl+Z / Ctrl+Y | 撤销/重做 |
| Ctrl+S | 保存 |
| Ctrl+滚轮 | 缩放时间线 |

文本框正在输入时，编辑快捷键交给文本框。中文输入法开启时，时间线焦点下的字母快捷键仍可使用。先选择效果，再将播放头放到效果内部，可执行分割或裁切；摄像头素材轨和音轨暂不支持 S/Q/W，可拖动边缘裁切。完整效果粘贴使用时间线悬浮位置或播放头作为起点；属性粘贴需先选中同类目标片段。可右键清除导出范围。

## 预览、项目与恢复

预览和导出共享场景与 D3D11 渲染器。实时预览不会先导出整段视频；首次有声播放需要准备混音音频缓存，长音轨可能等待。设置可选择960/1440/1920宽预览和30/60fps，实际速度取决于素材、效果与显卡。

编辑自动保存 `.frametrail` 工程并保留前一版 `.bak`；打不开项目时可恢复备份，损坏原文件另存。素材缺失时应用提供重新定位，并将所选素材复制进工程。删除项目使用回收站，避免直接永久删除。

“导入 DogSC 项目”支持schema23–27并创建新副本。转换差异写入 `dogsc-import-report.json`，原工程保持完整；目前仅有构造fixture验证，真实Mac项目和往返兼容尚未验收。

选中屏幕片段后，在声音面板的“所选片段音量”中单独调整系统声音与麦克风；“恢复全片音量”清除当前片段的覆写。分割片段会复制当前音量设置，之后可分别修改。

添加柔化片段后，可将“处理方式”改为“聚光”，用“区域外压暗”突出清晰的选区。“随源画面缩放和倾斜”开启时，选区跟随录制画面移动；关闭时，选区固定在输出画布上。可直接在画布中移动选区、拖角调整尺寸，并设置进入、退出和转场。

录制设置内的“恢复未完成录制”可检查已封装主视频、视频分段和独立轨道。恢复会生成新文件，不覆盖原素材；没有可解码帧的损坏视频不能保证恢复。缺少时钟数据时应用给出手动校准说明。

## 导出与排错

点击右上“导出”，选择MP4视频或M4A声音、文件名和目录。可用原始素材尺寸、1080p、1440p或4K，帧率30/60fps；竖画布保持竖向比例。已选择导出范围时，声音、光标、相机与效果使用同一区间。没有可用声音时M4A导出会明确报错。

编码器先实际探测，并在不可用时尝试后备编码器。窗口显示处理阶段、实际进度、耗时及稳定后才给出的剩余估算。取消会停止本次导出并清理临时文件；成功完成后可打开文件或目录，失败可修正原因后重试。

错误日志位于 `%LOCALAPPDATA%/FrameTrail/logs/errors.log`。录制依赖 Windows Media Foundation、Microsoft Visual C++ x64 Runtime和显卡驱动；便携包自带.NET与FFmpeg。安装器不会自动安装系统级运行库。

0.2.2音频采集采用WASAPI包首帧时间戳，短片50ms目标尚未稳定通过；新版长录数据见 [采集验证](capture-validation.md)，旧版30分钟结果不能代替新版验证。物理麦克风/摄像头、多显示器混合DPI和干净虚拟机仍待验证。完整数据见 [验证报告](validation-report.md) 与 [已知问题](known-issues.md)。当前包未签名，供本地交付和验收。

鼠标移动手感可在“光标 → 移动平滑”切换。光标时间对齐分组支持提前/延后 10ms，并与移动平滑参数独立保存。样机页提供窗口、浏览器、手机和平板预览卡片；框体比例、顶栏高度和外圆角可以分别调整。

“光标 → 跟随录制”在箭头、手型和文本形态间随录制事件切换，也可选固定样式。移动倾斜有自然、明显、强烈三档；点击反馈可设脉冲、柔光、涟漪或迸发，并调整持续时间、范围和不透明度。

缩放、屏幕 3D 和摄像头动画选择“自定义”后，可拖动 Bezier 控制点，或展开数值输入精确设置。选择“弹簧”后可调整项目共享的质量、刚度与阻尼。开场面板提供聚拢、侧滑、轻 3D 及顺滑、利落、柔和三种节奏，支持元素顺序和错峰；其它起始姿态放在“自定开场与起始姿态”折叠区。
