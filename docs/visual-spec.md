# DogSC 原版界面静态验收参考

本文件把上游 README 的四张界面图与源码中的布局常量整理为 FrameTrail 的静态外观验收依据。截图用于观察排布、密度、控件层级和颜色，不是 Windows 字体栅格化的像素级目标。图像和上游品牌资源只作为内部迁移审阅材料，不得复制到 FrameTrail 发布界面或图标。

## 设计基准

主编辑器采用浅色、近白灰背景、细线分隔、柔和圆角卡片和轻阴影；工作区用稀疏点阵作底，画面预览处于视觉中心，左侧悬浮工具栏和右侧检查器包围预览，时间线占据窗口底部。操作强调色用于当前选择和交互，红、橙、绿保留给录制/内容状态。画布与检查器之间有足够留白，不能让设置面板压缩到不可读。

`editor.png` 与 `motion.png` 为 3840×2498 像素的 Retina 截图，按 2 倍比例可参考约 1920×1249 pt 的大窗口。`EditorWorkspaceLayout` 源码给出最小窗口 840×600 pt、常规顶栏 72 pt、常规外边距 16 pt、时间线间隔 12 pt、左工具 rail 72 pt、检查器逻辑宽约 384–432 pt（检查器自身可调 340–480 pt）。时间线常规首选高度约 300 pt，但会按窗口可用高度和可见轨道收缩；不要把单张截图中的比例误当成固定像素值。窗口变窄时源码同步压缩 chrome，预览图和时间线文档仍使用原坐标比例。

## 编辑器布局和控件顺序

顶栏左侧依次是项目打开/最近项目入口、项目标题（可编辑）、删除项目；右侧依次是撤销、重做、场景预设、导出、设置、外观切换。画布顶部浮动条包含画面比例选择、裁切、添加元素、画面设置入口。左 rail 标签依次为画面、开场、运镜、光标、摄像头、声音；没有相应轨道时，标签仍可点击并显示空状态或导入入口，这是 Windows 版的操作差异，不会禁用入口。

画面检查器的二级页签为背景、布局、样机。背景页还有壁纸、网格、动效、自定来源选择。检查器以分组呈现控制项，不用长串无标题滑杆。时间线底部的轨道名称和轨道内容水平对齐；可见轨道由下拉菜单控制，支持缩放、屏幕 3D、摄像头动画、贴图/柔化和同步修正等轨道。没有数据的可选轨道不应制造虚假片段。

时间线控制条从左至右：分割、删除、恢复剪辑模式、画面/波形显示方式、标记；中央上一帧、播放/暂停、下一帧和当前/总时长；右侧吸附开关、悬浮预览开关、适配全时间线、缩小、缩放滑杆、放大。刻度和主素材剪辑始终共用横向时间坐标，播放头覆盖所有轨道。片段可通过两端裁短、整体拖动重排，拖动相邻接点时支持吸附；Shift 临时跳过吸附。时间线缩放滑杆按对数映射且保持合理视口锚点，不能用窗口整体缩放代替时间线缩放。

## 验收记录方法

静态验收需要保存 FrameTrail 同类项目在相近窗口比例下的截图，并对照表格逐页记录“通过/差异/未验”。运行状态和空状态都要检查：空项目不能显示虚构轨道内容；有媒体时，画布、检查器和时间线必须同时出现。验收文档应注明 Windows 分辨率、DPI、窗口尺寸、应用版本和项目素材；不能把 Retina 像素与 Windows 逻辑像素直接比较。
