# 桌面常驻与口播提词器

本文记录 FT-07 当前开发分支的交互与验收范围。托盘、独立浮窗、单实例唤回和提词器已经接入代码；真实桌面验收尚未完成，0.2.8 发行包不包含这些修改。

用户指出旧版录制工具依附主编辑器、退出后无后台入口，且缺少可用的口播阅读模式。本次按固定上游的独立录制面板与菜单栏常驻行为，改为 Windows 托盘管理窗口；界面沿用统一主题菜单与浮窗外壳。验收覆盖启动、隐藏、找回、录制中关闭编辑器、文稿编辑与阅读、保存和明确退出。

## 目标行为

- 普通启动先显示独立录制工具。主编辑器关闭时隐藏到系统托盘，应用继续运行；托盘菜单可显示编辑器、显示录制工具、打开提词器和明确退出。再次启动同一应用时召回现有实例；打开工程时显示编辑器。
- 录制设置浮窗与主编辑器分开管理。主编辑器隐藏或关闭后，浮窗仍可显示；录制期间浮条可用，录制结束后回到可找回的录制工具状态。
- 备忘录保留编辑与阅读模式及手动滚动，并增加自动提词滚动。用户可开始/暂停滚动、调整速度、回到文稿开头；文字、字号、背景透明度和窗口位置自动保存。
- 明确退出时先安全结束或处理正在进行的录制，再退出应用；托盘入口和普通窗口入口遵循同一退出行为。

上游 `RecorderMemo.swift` 有编辑/阅读模式、手动滚动、字号和背景不透明度调节；没有自动滚动或提词速度控制。本迁移增加自动滚动能力，默认暂停，切换编辑或关闭时停止。

## 当前后台验证

Release 构建为0警告、0错误；Core、导入及应用离屏回归通过。`artifacts/validation/desktop-residency/memo-v2/result.json` 的71项检查覆盖文稿保存失败/恢复、旧设置兼容、滚动算法、有限坐标和浅深布局；`surfaces-v2/result.json` 的11项检查使用同一个实际录制浮窗验证主题更新、控件边界和无 Owner；`ipc-final/result.json` 的6项检查用隔离命名管道和不同线程验证主/次实例、唤回确认、无效请求和释放恢复。它们不证明真实托盘菜单、跨进程启动、捕获期间窗口独立或成片排除行为；这些仍按下方普通操作验收。

## 普通操作验收

逐项在实际桌面运行候选版本并记录结果；在取得实际证据前保持未验收。

1. 启动应用，确认只显示录制工具且托盘图标可用；再次启动，确认召回同一进程且不产生第二个浮窗。
2. 从托盘显示主编辑器，再隐藏主编辑器并从托盘打开录制工具。
3. 拖动录制工具后关闭并再次打开，确认能找回；主编辑器隐藏时也能操作录制工具。
4. 开始一次真实录制，隐藏或关闭主编辑器，确认托盘和录制浮条仍能控制录制；从托盘恢复后正常停止。
5. 打开备忘录，输入并粘贴多段文稿，切换阅读/编辑并手动滚动，确认阅读模式不会误改正文。
6. 开始自动滚动，调慢/调快速度、暂停、继续并回到开头，确认文稿按控制移动且输入焦点操作可用。
7. 调整字号和背景透明度，收起后重开并重启应用，确认正文和偏好保留。
8. 使用托盘“退出”结束应用；再次启动，确认能重新显示编辑器、录制工具和已保存文稿。

对录制中的关闭/退出操作另核对提示、录制文件可解码和临时文件清理。该项与本清单的普通窗口操作一并记录，不以窗口出现或控件可点击代替录制结果证据。
