# 桌面常驻与口播提词器

本文记录 FT-07 的交互与验收范围。0.2.11已由用户确认托盘菜单稳定、明确退出、提词器文稿和外观重启恢复、重复启动召回同一进程，以及关闭编辑器后录制继续并可从录制条结束。用户反馈无法打开录制条菜单，0.2.12已加入齿轮菜单；新录制条菜单和提词器、菜单及最近项目子菜单的录屏排除仍待实机验收。0.2.12还更新了时间线预览交互，详见 [`release-0.2.12.md`](release-0.2.12.md)，不改变 FT-07 的实机待验范围。下方保留0.2.9历史结果，不将旧失败或离屏探针混作当前实机结论。

用户指出旧版录制工具依附主编辑器、退出后无后台入口，且缺少可用的口播阅读模式。本次按固定上游的独立录制面板与菜单栏常驻行为，改为 Windows 托盘管理窗口；界面沿用统一主题菜单与浮窗外壳。验收覆盖启动、隐藏、找回、录制中关闭编辑器、文稿编辑与阅读、保存和明确退出。

## 目标行为

- 普通启动先显示独立录制工具。主编辑器关闭时隐藏到系统托盘，应用继续运行；托盘菜单可显示编辑器、显示录制工具、打开提词器和明确退出。再次启动同一应用时召回现有实例；打开工程时显示编辑器。
- 录制设置浮窗与主编辑器分开管理。主编辑器隐藏或关闭后，浮窗仍可显示；录制期间浮条可用，录制结束后回到可找回的录制工具状态。
- 备忘录保留编辑与阅读模式及手动滚动，并增加自动提词滚动。用户可开始/暂停滚动、调整速度、回到文稿开头；文字、字号、背景透明度和窗口位置自动保存。
- 明确退出时先安全结束或处理正在进行的录制，再退出应用；托盘入口和普通窗口入口遵循同一退出行为。

上游 `RecorderMemo.swift` 有编辑/阅读模式、手动滚动、字号和背景不透明度调节；没有自动滚动或提词速度控制。本迁移增加自动滚动能力，默认暂停，切换编辑或关闭时停止。
