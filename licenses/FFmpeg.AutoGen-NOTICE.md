# FFmpeg.AutoGen 许可告知

本项目通过 NuGet 包 `FFmpeg.AutoGen.Bindings.DynamicallyLoaded` 8.1.0 使用 FFmpeg.AutoGen C# 绑定；锁文件中的传递依赖 `FFmpeg.AutoGen.Abstractions` 也是 8.1.0。两包声明的许可证均为 MIT，随包 `LICENSE.txt` 的副本见 `FFmpeg.AutoGen-MIT.txt`。

来源已按本项目还原的 8.1.0 NuGet 包核对：包 nuspec 中标注 `license type="file"`，仓库地址为 `https://github.com/Ruslan-B/FFmpeg.AutoGen`，提交为 `444925cd53d3611fd4c8c295873fb631be56ab21`。此告知只适用于 FFmpeg.AutoGen 8.1.0，不代表其他版本或原生 FFmpeg 库的许可证。
